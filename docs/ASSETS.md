# Asset Manifest & Licensing

This document tracks all third-party and custom assets used in *Herbert's Zoomies*.

## Asset Policy
1. Priority 1: Original procedural / vector rendering generated in code.
2. Priority 2: CC0 / Public Domain assets.
3. Priority 3: Permissive open-source assets (MIT / Apache 2.0 / CC-BY) with full attribution.
